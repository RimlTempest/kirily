# 書き終えたあとの確認

## 型

- [ ] `any` / `as`（`as const` 以外）/ `!` / `class` / `enum` を書いていない
- [ ] 新しい状態は判別可能ユニオンになっている（boolean の組み合わせではない）
- [ ] `switch` は `assertNever` で閉じてある
- [ ] 失敗は `Result<T, KirilyError>` で返している
- [ ] 新しい `KirilyErrorCode` にユーザー向け文言を足した
- [ ] 座標は `ImagePoint` / `ScreenPoint` で区別されている

## 画像処理

- [ ] 巨大バッファを戻り値で新規確保していない（書き込み先を引数で受け取る）
- [ ] Export が Preview ではなく元画像から始まっている
- [ ] マスクの長さを関数の入口で検証している
- [ ] 中間フォーマットに JPEG を使っていない

## 依存

- [ ] 時計・乱数・fetch・エンジン・プロバイダを引数で受け取っている
- [ ] `packages/image-core` と `packages/editor-core` に DOM が出てこない
- [ ] Svelte コンポーネントが WASM / AI プロバイダを直接呼んでいない

## テスト

- [ ] 実装より先にテストを書いた（赤を確認した）
- [ ] エラー枝のテストがある（`ok` だけのテストは半分）
- [ ] 境界値がある（0 / 1 / 上限 / 上限+1、画像の端）
- [ ] 時刻・乱数に依存していない
