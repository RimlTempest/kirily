# ADR-0006: マスクを base / keep / remove の 3 層で持つ

- 状態: 採用
- 日付: 2026-09-21

## 背景

AI 補正やモデルの再実行を行うと、ユーザーがブラシで直した結果が
上書きされてしまう。`kirily-design.md §8` はこれを明確に禁じている。

単一のマスクを持つと、AI の出力とユーザーの入力が区別できず、
「AI を再実行したら手直しが消えた」を避けられない。

## 決定

元解像度のマスクを 3 枚持ち、合成して最終マスクを作る。

```text
final = max(base, keep) - remove
```

- `base` — AI の出力。再実行で丸ごと置き換わる
- `keep` — ユーザーが「残す」と塗った強さ（累積、255 で飽和）
- `remove` — ユーザーが「消す」と塗った強さ

メモリは元解像度 × 4 枚（3 層 + 合成結果）。4K で約 33MB。
Preview 用は `resampleMask` で都度作る。

## 結果

- AI の再実行が手作業を壊さない
- ブラシの取り消しは、その層の該当領域を書き戻すだけで済む
- メモリを食う。8K 以上では層を統合するなどの最適化が要る
  （そのときも `composeMask` の API は変えない）

## 代替案

- 単一マスク + 履歴からの再生 → 再実行のたびに全履歴を再適用することになる
- keep/remove を 1 枚の符号付きマスクに → 「両方塗った」の表現が壊れる
