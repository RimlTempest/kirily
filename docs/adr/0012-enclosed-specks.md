# ADR-0012: 囲まれた小さい穴を閉じる

- 状態: 採用
- 日付: 2026-09-21

## 背景

ADR-0007 の `solidifyInterior` は「モデルが自信を持って背景と言った画素
（alpha ≤ 24）は触らない」ことで、マグカップの取っ手のような
**本物の穴**を守っている。

その規則が誤爆する。`pale-subject-on-white.png` を濃い背景に置くと、
髪の中の白いハイライトが抜けて見える。

計測（IS-Net 段、書き出した 1254² のアルファ上で、
画像の縁から辿れない背景の連結成分）:

| 成分               | 面積        | 画像比      | 位置       |
| ------------------ | ----------- | ----------- | ---------- |
| 髪の白いハイライト | 794 px      | **0.0505%** | (92, 606)  |
| 同（断片）         | 54 px       | 0.0034%     | (75, 670)  |
| 目尻の点           | 30 px       | 0.0019%     | (782, 965) |
| ほか 40 個         | 各 1〜18 px | —           | —          |

一方、ADR-0010 の評価セットにある**本物の穴**は画像の **6.6%**。
130 倍の開きがある。

### guided filter は原因ではない

`refineMask` を外して測ると、囲まれた成分は 11 個 48px から
**44 個 1061px に増える**。guided filter は穴を修復している側で、
開けているのはモデル自身である。推測せず両方測って確定した。

### 除染も原因ではない

背景フィールドを `null` にして書き出しても画素は同一だった。
濃紺の上で紫っぽく見えるのは、中間アルファの画素越しに
背景が透けているだけである。

## 決定

**囲まれた背景の連結成分のうち、画像の 0.1% より小さいものを塞ぐ。**

面積が唯一の判別軸になる。取っ手、腕と胴の隙間、指輪の中 —
どれもモデルが残す斑より桁違いに大きい。

**色では分けられない。** 直したいケースがまさに
「白い背景に対する白いハイライト」だからである。

閾値 0.1% は、観測した最大の誤穴（0.05%）の 2 倍、
評価セットの本物の穴（6.6%）の 66 分の 1 に置いた。

ランプを付けずに一気に不透明にする。この斑は四方を被写体に
囲まれているので、ここに守るべき輪郭は無い。

## 結果

利用者が赤で指した 4 箇所のうち、**髪の白いハイライト 2 箇所が解消**した。
襟の 2 箇所は残る（後述）。

評価セットは CPU 段・GPU 段とも全項目通過。
`ring-with-hole` は落ちていない。ただしこのケースは
**モデルが元から穴を埋めてしまうので、閾値の上限側を検証していない**。
上限側を守っているのは `mask.test.ts` の
`keeps a hole that is large enough to be something`（画像の 9%）である。

## 残る課題：白いシャツと背景

襟の 2 箇所は囲まれた穴ではない。背景が画像の縁まで繋がっているので、
この手法は届かない。モデルが白い襟と白い背景の境界を見つけられていない。

利用者の報告によれば remove.bg でも同じ破綻が起きる。研究でも
「白い穴が大きすぎて精緻化で直せない画像が 1/3 あった」と報告されている
既知の難所である。

ただし**この画像に限れば、色だけで分離できる**。計測:

| 領域               | 色                   | 背景からの OKLab 距離 |
| ------------------ | -------------------- | --------------------- |
| 背景自身のばらつき | `#fafafa`〜`#fcfcfb` | **0.0030**            |
| 白いハイライト     | `#ffffff`            | 0.0152                |
| **白い襟**         | `#f4f4f7`            | **0.0187**            |
| 肌                 | `#fef5ef`            | 0.0150                |
| 青い髪             | `#759ecd`            | 0.3090                |

背景は非常に狭いクラスタで、襟はその 6.3 倍外側にいる。
フラットな色で描かれたイラストなので分離しやすい条件であり、
写真ではここまで綺麗には分かれない。

次の一手は ADR-0011 の `BackgroundField` を使った
**色差マッティング**になる。`I = αF + (1-α)B` で B は既に持っているので、
前景色 F を局所推定すれば α が色から直接出る。
二値化ではなく α を出すことが要点で、
閾値で切ると ADR-0008 が守っている柔らかい髪の輪郭を潰す。
